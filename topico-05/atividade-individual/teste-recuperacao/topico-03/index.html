Sobre esta iniciativa

Este pequeno site documenta, de forma pública e organizada, o percurso prático do Módulo 4 (Linux e Segurança na Cloud) do programa Upskilling Digital, da Skodji Digital. Serve também como exercício prático de publicação de um serviço web num ambiente Linux, usando um servidor web real.

Componentes usados nesta publicação

  • Sistema operativo: Ubuntu 22.04.3 LTS (WSL2)
  • Servidor web: Nginx
  • Linguagem de marcação: HTML5
  • Estilos: CSS3 (ficheiro style.css)
  • Controlo de versão: Git / GitHub
